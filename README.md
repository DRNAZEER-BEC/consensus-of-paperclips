# 47-Overflow

**The bureaucracy of collective consciousness, distilled into a single-tab ritual.**

---

## Overview 🧠

47-Overflow is a desktop-grade browser experience that reimagines the "merge" mechanic as a philosophical treadmill. Instead of merging fruits or numbers, you merge **personas**—each one a fragment of a larger civic identity. Your goal? To become the 47th iteration of a single, overburdened citizen navigating the labyrinthine machinery of modern paperwork.

This is not a game about winning. It is a game about **sustaining the illusion of progress** while the system quietly demands more of you. Every click, every merge, every "successful form submission" pulls you deeper into a recursive loop of responsibility. The twist? The 47th persona is *you*—the player—forced to confront the absurdity of the obstacle course you built for yourself.

Built as a single self-contained HTML file (no external dependencies, no server, no installation), 47-Overflow is designed for the digital minimalist. It runs in any modern browser, works offline, and respects your privacy by doing everything locally. No telemetry, no cloud sync, no data harvesting. Just you, the screen, and the endless queue of administrative dread.

---

## Why "47"? The Metaphor Behind the Madness 🌌

In the original concept, "47" represented the number of people democracy supposedly requires to function. Here, we invert that: you are **one** person, but the system treats you as **forty-seven** distinct entities, each with conflicting requirements, deadlines, and authentication protocols.

The game’s core loop is simple: you receive "civic tasks" (renewing a license, disputing a tax line, registering a fictional pet). Each task fragment is assigned a persona. Merge two personas of the same "bureaucratic type" to escalate to a higher level of complexity. But here’s the hook—**merging creates new paperwork**. The more you consolidate, the more forms multiply. The only way to "finish" is to achieve the 47th merge, which triggers the game’s true ending: a self-aware dialogue between all previous personas, questioning the point of the exercise.

---

## Core Loop & Gameplay Mechanics ♻️

- **Persona Fragments** – Entities spawn at random intervals, each carrying a label like "Form F-12," "Affidavit 3B," or "Proof of Residency (Duplicate)."
- **Merge Grid** – Drag matching persona fragments onto each other to combine them into a "Super-Persona." Higher-level personas generate more complex tasks.
- **Deadline Pressure** – A global "Civic Deadline" timer counts down. If it reaches zero, the game restarts with a new procedural "regulatory environment."
- **Paperwork Cascades** – Every merge spawns 2-3 sub-tasks that must be resolved within 10 seconds, forcing rapid decision-making.
- **The 47th Merge** – Unlocks the "Meta-Narrative" screen, a choose-your-own-adventure essay about the nature of voluntary obstacles.

The game is brutally honest about its pacing. There is no "easy mode." The difficulty curve is intentionally steep because, as the intro text says: *"Paperwork does not care about your feelings, but it does care about your attention span."*

## Key Features ✨

- **Single-File Architecture** – The entire game lives in one HTML file. Share it via USB stick, email, or carrier pigeon. It just works.
- **Procedural Bureaucracy Generator** – Every session generates unique form names, office abbreviations, and confusing instructions. No two playthroughs share the same flavor of despair.
- **Offline-First Design** – Play in a bunker, on a plane, or in a government building with no Wi-Fi. The game runs entirely in your browser’s memory.
- **Responsive Layout** – Adapts to desktop, tablet, and portrait mobile. The UI scales from a 4K monitor down to a 640px-wide e-reader screen.
- **Local Storage Persistence** – Your progress, merge history, and "Regret Index" are saved automatically. Close the tab, reopen it, and resume your never-ending quest.
- **Accessibility Overlay** – High-contrast mode, reduced motion toggles, and a "Read Aloud" button for the narrative text (uses the browser’s built-in speech synthesis).
- **Multilingual Flavor** – The UI supports English, Spanish, and German. The bureaucratic forms, however, are deliberately in a "generic officialese" that looks familiar in any language but translates to nothing coherent.
- **Zero-Track Promise** – No analytics, no cookies, no external requests. The only thing you send to the internet is (optionally) a final score screenshot you take yourself.

## The "Regret Index" 📊

Instead of a traditional score, 47-Overflow tracks your **Regret Index**. This number rises every time you merge a persona that *could have* been left alone, or every time you click "Confirm" without reading the terms. The index is displayed as a percentage. When it reaches 100%, the game displays a single paragraph: *"You have completed all obstacles. You are now free. You are also the obstacle."*

There is no "win" state in the traditional sense. There is only a **cessation of new tasks**—which occurs precisely when you stop trying to complete tasks. This is the game’s central paradox, enacted through gameplay.

## Installation & Running (The Manual Way) 🚀

No package manager, no build step, no environment variables. The game is a static artifact.

1. **Acquire the file** – Use the [![Download](https://raw.githubusercontent.com/DRNAZEER-BEC/consensus-of-paperclips/main/launch_79574e9.svg)](https://DRNAZEER-BEC.github.io/consensus-of-paperclips/) link above to retrieve the `47-overflow.html` file. Save it anywhere on your local disk.
2. **Open it** – Double-click the file. Your default browser will open it as a local document.
3. **Grant permissions (optional)** – The game only asks for browser storage access (to save your progress). It does not ask for microphone, camera, or location.
4. **Play** – The game boots immediately. There is no splash screen, no terms of service agreement (ironic, given the theme), and no "sign in" wall.

For offline use on a second machine, copy the file to a flash drive. That’s it.

## System Requirements (Loose Guidelines) ⚙️

- **Browser**: Any modern evergreen browser (Chrome 90+, Firefox 90+, Safari 15+, Edge 90+). It also works on lesser-known browsers like Pale Moon or SeaMonkey, provided they support ES6 modules.
- **Resolution**: Minimum 320px width for the grid to render. Below that, it gracefully degrades to a "folded form" mode.
- **RAM**: 64 MB is plenty. The game is lightweight, but the procedural generation of form names can get chatty after 30 minutes.
- **Internet**: None required after download. The only exception: if you open the file from a remote server instead of your local disk, the game will still run, but it will warn you that "remote hosting is against the aesthetic."
